# Frontend Client — Academic Certificate Verification Portal

React 18 + Vite client providing the administrative management dashboard and the zero-login public verification portal.

## Features
- **Admin Dashboard & CRUD:** Students, Academic Results, and Certificate Issuance
- **Printable Academic Certificate:** Classic institutional frame, gold seal, signatures, and dynamic QR code
- **Public Verification:** Scans QR code or takes manual ID input to recalculate SHA-256 and verify against blockchain
- **Live Tampering Demonstration:** Real-time demonstration button to show blockchain tamper-evidence

## Running Locally

```powershell
npm install
npm run dev
```

The app will be available at `http://localhost:5173`.
